# VQT 频谱分析方案可行性调研报告

> 版本：v0.4.0 ｜ 日期：2026-10-11
> 状态：**已采纳并落地**——本文档先作为可行性调研立项，随后经离线原型实测验证（数据见 §6），随 v0.4.0 完成插件集成。回归测试 174 项全部通过，Release x64 零警告。

---

## 1. 背景与结论（TL;DR）

原频谱可视化采用「单次定长 FFT + 段中心单点功率插值」：8192 点 FFT @48 kHz 的 bin 宽 5.86 Hz，而显示范围 0.5–500 Hz 跨**十个倍频程**。定量结论（v0.3.4 代码坐实，`SubEQ_Spectrum.cpp:154-179`）：

- 61 段模式（1/6 oct）中**前 22 段**、121 段模式（1/12 oct）中**前 44 段**的段中心低于第一个有效 bin，全部直接复制 bin 1 的功率——0.5–5.86 Hz 的"频谱"实际上是同一个值的复制；
- 85 Hz 以下约 45/61 个频段由仅 14 个 bin 插值驱动；
- 窗函数固定 Hann（首旁瓣 −31.5 dB），相对 −60 dB 显示动态范围，强单音泄漏会涂脏远端频段，且不可配置。

**结论：可行且值得做。** 采纳**多采样率 VQT（Variable-Q Transform）滤波器组**（Schörkhuber–Klapuri / librosa 风格的倍频程分层 + Brown–Puckette 频域核），并以**可选窗函数族**（Hann / Blackman / Blackman–Harris / Nuttall）作为显示设置。实测收益：

| 指标 | 旧方案（FFT 8192） | 新方案（VQT，121 段 BH Balanced） |
|---|---|---|
| 0.5–5.9 Hz 频段 | 复制 bin 1（无意义） | 独立估计（2 s 窗，gamma 化带宽） |
| BH 窗下 +3 频段泄漏 | n/a（固定 Hann ≈ −40 dB @2 段） | **< −200 dB（数值零）** |
| 满幅正弦校准误差 | 依赖插值，段间可达数 dB | ≤ 0.75 dB（gamma 区外） |
| 单分析器 CPU（5 s @48k 实测） | 49.6 ms | **10.5 ms（4.7×）** |
| 窗型/分辨率 | FFT 点数三档 | 窗型四档 × 分辨率三档，均为显示设置 |

## 2. 现状缺陷定量分析

### 2.1 线性频率分辨率与对数显示的根本错配

bin 宽 = fs/N 恒定；显示网格 `fc = 0.5·2^(n/div)` 对数。两者交叉处即失效点：

| FFT 点数 | bin 宽 @48k | 段间距 @0.5 Hz（1/12 oct） | 需要的 N（0.5 Hz 处 1 bin/段） |
|---|---|---|---|
| 4096 | 11.7 Hz | 0.0295 Hz | ~1.6M |
| 8192 | 5.86 Hz | 0.0295 Hz | ~1.6M |
| 16384 | 2.93 Hz | 0.0295 Hz | ~1.6M |

单纯增大 N 无法收敛：0.5 Hz 段间距需要百万点 FFT（>20 s 窗口），且全频段时间行为同步恶化。这是"固有缺陷"的数学本质：**定长线性变换在对数显示上底部必然欠采样、顶部必然过采样**。

### 2.2 时间-频率耦合

单窗口 171 ms（8192 @48k）对 500 Hz 内容过短（欠平滑）、对 0.5 Hz 内容过短 8 倍以上（不足一个周期）。hop 与包络时间常数进一步耦合（hop 变化隐式改变视觉响应速度）。

### 2.3 能量口径

段幅值 = 段中心单点功率插值（非频段能量积分）：噪声底形状、宽带信号的显示都与真实倍频程能量分布不一致。

### 2.4 窗函数不可配置

Hann −31.5 dB 旁瓣 vs −60 dB 显示范围：一个 50 Hz 踢鼓即可点亮 0.5–8 Hz 整段（旧实现靠 bin 1 插值部分掩盖，但本质存在）。用户无法在"分辨率"与"泄漏抑制"之间取舍。

## 3. 候选方案对比

| 方案 | 原理 | 频率分辨 | 时间行为 | 音频线程成本 | 实现风险 | 结论 |
|---|---|---|---|---|---|---|
| A. 增大单次 FFT（131072） | 复用现有 twiddle 基础设施 | 0.37 Hz/bin，0.5 Hz 处勉强 | 2.7 s 窗**全频段**拖尾 | ~10× 现状 | 低 | 否——高频时间行为不可接受 |
| B. 多分辨率拼接（MRFFT） | 高频小 FFT 快跳 + 低频大 FFT 慢跳，接缝拼接 | 分区良好 | 分区良好 | ~2× 现状 | 中——接缝连续性/相位拼接 | 备选——VQT 的退化特例（两层） |
| C. **多采样率 VQT 滤波器组** | 倍频程分层降采样 + 每层定长 FFT + 频域匹配核 | 每倍频程恒定（尺度不变） | 窗长逐层 ÷2（对数时间） | **~0.2× 现状** | 中 | **采纳** |
| D. 滑动谐振子/Goertzel 组 | 每段一个滑动谐振器 | 同 C | 逐样本连续 | 低 | 高——校准/窗形/双频镜像处理复杂 | 否 |

方案 C 的关键优势：层内归一化坐标恒定（恒 Q 的尺度不变性），10 层共享同一套设计参数；GUI 段网格与 `getSpectrum` API 完全不变（GUI 端零改动）；复用 `SubEQ_DSPMath.h` 的 radix-2 FFT 与 twiddle 多槽缓存、`SubEQ_Biquad.h` 的双精度抽取滤波器。

## 4. 采纳方案设计（已实现，`SubEQ_VQTDesign.h`）

### 4.1 层结构与帧长

- **10 个倍频程层**：层 o 覆盖 [0.5·2^o, 0.5·2^(o+1))；顶层（256–512 Hz）从全率降到 ~3 kHz（48 kHz → ÷16；44.1 kHz 受整除约束 ÷4 = 11025 Hz），向下每层再 ÷2。
- **帧长（= 核窗长）**：
  - 分辨率需求：`F_res = ⌈分辨率倍率 × filterScale × R_o / 段间距⌉` 取 2 的幂。分辨率倍率 = 主瓣零点宽/2（Hann 1、Blackman 1.5、BH-4/Nuttall 2——**低旁瓣窗的主瓣代价诚实计入**）；filterScale = Fast 0.7 / Balanced 1.0 / Fine 1.5。
  - 2 s 封顶（用户决策）：`F_cap` = 不超过 R_o·2 s 的最大 2 的幂——pow2 量化后**严格不超封顶**。
  - 层窗时长实测（48 kHz / 121 段 / Balanced）：Hann 自上而下 [0.085, 0.171, 0.341, 0.683, 1.365×6] s；BH-4 [0.171, 0.341, 0.683, 1.365×7] s——BH 主瓣加倍使满分辨层比 Hann 低一层，这正是窗型可选的意义。
- **步距**：层 o 每积累 `max(1, hop·R_o/fs)` 个层样本分析一次（与顶层 hop 实时锁步；底层步距钳 1）。

### 4.2 帧加窗 + 匹配核（架构关键决策）

原型第一版把窗全部放进核、帧不加窗——实测 BH 泄漏仅 −27 dB。根因：**未加窗帧的矩形谱裙（−13 dB，衰减 6 dB/oct）穿过核主瓣，Parseval 支撑截断的 cancellation 被破坏**。正确架构（已实现）：

1. 帧乘**选定窗型**（长度 = 帧长）→ FFT；
2. 每频段核 = 同窗复指数 `ψ[n] = w[n]·e^{−j2πf_k n/R}` 的频谱，支撑为 |K| 高于 −65 dB 峰值的连续区间（自峰扩展 +1 bin）；
3. 段响应 `r = Σ X[m]·conj(K[m])·2/S`（S = 支撑能量）——分数 bin 匹配估计，对支撑内任意截断**精确无偏**（分子分母同支撑相消）；
4. ×2 因子补回实信号正弦镜像损失（|r| = A/2 → A）。

**镜像支撑下限保护**：当峰位 bin `b_k = f_k·F/R` 小于主瓣零点半宽（底部 gamma 区，帧内不足 ~2 周期）时，正负频率镜像落进支撑，读数出现相位相依摆动——支撑下限抬到镜像主瓣之外（`m ≥ ⌈nullHalf − b_k⌉`）。

### 4.3 校准与直流

- 核内建相干归一：满幅正弦落段中心 → 功率 1 → 0 dB，**与旧分析器幅值约定一致**（校准实测 ≤ 0.75 dB，gamma 区外）。
- **0.05 Hz 一阶直流阻断**（0.5 Hz 处 −0.04 dB）：2 s 窗主瓣覆盖直流，无阻断则 DC 偏置会直接点亮底部频段。实测 0.3 DC 偏置 → 全部频段 < −30 dB。

### 4.4 抽取链

每级 ↓2 前 4 阶 Butterworth（两个 RBJ 低通 biquad，Q = 0.5412/1.3066），截止 0.35×输出率：折叠带压制 ≤ −70 dB（显示级），频段内容最高 ~0.17×层率，通带无衰减。级联共 13 级 @48k，成本 ~1 Mflops/s。

### 4.5 线程与内存模型（与旧实现的约束对齐）

- 24 个核组合（窗 4 × 密度 2 × 分辨率 3）在 `prepare()`（prepareToPlay 线程）全量预生成；`configure()` 只切 `activeSet` 指针 + 复位状态——F-011「三张 Hann 表」模式的推广，音频线程零分配。
- F-010 惰性 twiddle 预热保留（按层帧长）。
- 输出接口不变：`getSpectrum(float*) → 段数`，逐段 atomic。既有的"撕裂帧一帧自愈"问题保持不变（低频重配概率场景，可接受）。
- 内存：核组合 ~1.5–2 MB + 各层环形缓冲/scratch ~数百 KB × 2 分析器。

## 5. 窗函数族专章

### 5.1 候选窗对比（文献值 + 原型实测）

| 窗 | 首旁瓣 | 主瓣（零点宽） | ENBW | 分辨率倍率 | 实测校准误差 | 实测 +3 段泄漏 |

### 5.2 采纳集合与默认值

- **UI 四档：Hann / Blackman / B-Harris / Nuttall**（`spectrum_window` 参数，默认 **B-Harris**——研究动机即泄漏问题；Hamming/Blackman–Nuttall/Kaiser/Flat-top 作为本表对照弃用）。
- 窗型语义：相邻段重叠（BH ±1 段 ~−6 dB 肩部、远端干净）vs Hann 相邻段在零点（段间深谷、±2–3 段 −40 dB 裙摆）——**两种"形状美学"都是合法显示选择**，交给用户。
- **主瓣×2 s 封顶交互**（已披露给用户）：BH/Nuttall 主瓣加倍 → 满分辨交叉点上移约一个倍频程（48k/121/Balanced 下 Hann 约 2.3 Hz 以上满分辨、BH 约 4.6 Hz 以上）。

## 6. 原型验证结果（`Tests/subeq_fft_test.cpp`，174 项断言全通过）

- **校准**：四窗型 × {0.5, 1, 4, 16, 63.5, 200, 453} Hz 段中心满幅正弦 → gamma 区（0.5 Hz，<2 周期/窗）最差 −2.8 dB（容差 ±3.5，相位相依摆动），其余 ≤ 0.75 dB。
- **泄漏**：100 Hz 满幅单音，BH +3/+5 频段 < −200 dB（数值零）；Hann −77/−74 dB（对照）。
- **直流**：0.3 偏置 12 s → 全部频段 < −30 dB。
- **双音分辨**：28/34 Hz 各 −6 dB 源 → 两中心段各读 ~−6 dB、落不同段。
- **2 s 封顶**：全 24 组合所有层窗时长 ≤ 2.0 s（pow2 量化严格成立）。
- **性能基准**：5 s @48k 单分析器（121 段 BH Balanced）**10.5 ms vs 旧方案 49.6 ms（4.7×）**；默认 61 段 Hann 约 3×。
- **层结构**：抽取阶梯、band 划分总和、帧长 pow2、支撑界内等不变量。

## 8. 已知限制与风险

1. **gamma 区相位摆动（接受）**：0.5 Hz 段（2 s 窗 <1 周期）读数有 ±2~3 dB 的慢速相位摆动——物理约束（用户已确认 2 s 封顶取舍）。缓解：镜像支撑保护 + 包络平滑。若后续观感不可接受，备选是给底层 1–2 层放宽封顶至 ~4–5 s（0.5 Hz ≥ 2 周期）。
2. **44.1 kHz 成本上浮**：pow2 抽取整除约束使 44.1 kHz 顶层只能到 11025 Hz（过采样比 21.5 vs 48k 的 5.9），帧长相应增大约 2×，成本回到旧方案量级。有理重采样可解，本次不做（记录为后续项）。
3. **噪声底口径变化**：段能量来自窗 ENBW × 层率带宽（层间 2× 阶梯），与旧"单 bin 取样"不同——噪声底形状更平（每倍频程恒定带宽比例），README 已说明。
4. **撕裂帧问题遗留**：段数与段数据分离原子的旧问题保持不变（一帧自愈）。
5. **prepare() 成本**：24 组合全量构建（~3k 次小 FFT + 三角函数）在 prepareToPlay 上下文数十 ms 量级，可接受。

## 9. 结论

VQT 方案在分辨率、泄漏、成本、校准、集成风险五个维度全面优于现状与替代方案，原型实测数据支撑直接集成。v0.4.0 已完成：

- `SubEQ_WindowFunctions.h` / `SubEQ_VQTDesign.h`（无 JUCE 纯数学，插件与测试共用）
- `SubEQ_Spectrum` 内核替换（多采样率 + 24 核组合预生成 + 零分配配置）
- 参数面与 UI（分辨率档语义迁移 + 新窗函数参数，老 session 兼容）
- 回归 102 → **174 项**；Release x64 零警告。
